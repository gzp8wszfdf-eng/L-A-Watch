# L&A One — React foundation

Изолированная React + TypeScript основа интерфейса L&A One в стиле Neon Pulse.

## Запуск
```bash
cd la-one
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

Это UI-прототип с демонстрационными данными. Авторизация, реальные сообщения, звонки, загрузка видео и серверная логика пока не подключены.

Папка `la-one/` отделена от корневого приложения L&A Watch. Не публикуйте её в production без отдельной настройки деплоя.
